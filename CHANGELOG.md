# Change log

This project is under active development. Entries describe design progress and do not imply a production release.

## Unreleased

- Added a two-layer 70 mm × 100 mm PCB outline with 8 mm corner radii.
- Increased trace widths for home PCB fabrication where routing clearance permits.
- Added a passive piezo buzzer on GPIO20 and moved it to the back of the PCB.
- Assigned the Select button to GPIO9.
- Added SCD40 CO₂ and other environmental sensor connections.
- Adjusted SHT40 and SCD40 placement for module clearance.
- Moved TFT1 1 mm right and 2 mm up for enclosure alignment.
- Rerouted copper around the relocated lower mounting hole.
- Added fabrication outputs, BOM, enclosure source, prototype photos, and build documentation.
- Documented the external USB-C programming extension.
